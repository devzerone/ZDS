# Button Accessibility Checklist

## Core Action Button

- [ ] Text label is always present and remains the primary action meaning
- [ ] Primary button remains readable against its active background
- [ ] Disabled button still appears discoverable rather than hidden

## Variant and Size Review

- [ ] Primary, secondary, tertiary, and destructive buttons remain distinguishable by meaning
- [ ] Small, medium, and large buttons preserve usable target expectations
- [ ] Repeated primary emphasis is flagged as misuse during review

## State and Icon Review

- [ ] Focus treatment is visible without relying on hover
- [ ] Loading state communicates progress and blocks repeated activation
- [ ] Leading and trailing icons support the label rather than replace it
